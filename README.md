# terrible-creepy-site

このサイトは、日々Webサイトを見て感じる『なんか嫌なサイトだな』と感じるポイントを掻き集めたサイトです。  
「もっと嫌なポイントあるやろ！」と感じた方は、ぜひIssueやPull Requestで追加をお願いします。

> **Note**  
> このプロジェクトは意図的に最悪なユーザー体験（Bad UX）を再現したジョークサイトです。

---

## Features (実装されている不快要素)

- **低いコントラスト:** 背景と文字の差が無く、絶望的に読みづらい
- **一方的なCookie警告:** 許可しか選べず、「選択内容を確認する」を押すとなぜか閉じる
- **リンク切れの「このページについて」:** 押すと当然の権利のように 404 Not Found
- **どでかい広告:** ファーストビューを盛大に邪魔する
- **PCファーストビュー:** モバイル? Who knows?
- **タブ非アクティブ時の不満:** 別タブに移るとページタイトルや画面で不満を主張
- **DevTools開口時の警告:** 開発者ツールを開いたユーザーを検知して警告
- **誤タップ必須トラップ:** 「Google検索でこのサイトをお気に入りに追加」ボタン
- **執拗なポップアップ:** 3秒毎に全画面広告が差し込まれる
- **露骨な資金援助:** ページトップで「運営を助ける支援をお願いします」と懇願

## 開発・閲覧方法

1. リポジトリをローカルにクローン
2. `index.html` をブラウザで直接開く
